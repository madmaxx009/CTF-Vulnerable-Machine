# GrapplerPWN – Custom CTF Vulnerable Machine

## Description  
**GrapplerPWN** is a custom-built vulnerable Linux machine designed for Capture The Flag (CTF) and ethical hacking practice. It simulates real-world attack scenarios, offering hands-on experience in penetration testing, vulnerability assessment, privilege escalation, and exploitation.
This machine is intended for cybersecurity learners, students, and ethical hackers looking to enhance their skills through practical challenges.

----

## Features  
Target OS: Linux 14
-  Multiple vulnerabilities including:
  - Misconfigured FTP
  - Web exploitation
  - SSH brute-force
  - Steganography
  - Cron job privilege escalation
-    Real-world attack vectors replicated
-    Designed to reinforce knowledge of Linux privilege escalation techniques
-    Great for use in labs, cybersecurity courses, or CTF competitions
Flags:
user1.txt - Obtainable via SSH
user2.txt - Obtainable via lateral privilege escalation
root.txt - Accessible only through a cron job exploit
